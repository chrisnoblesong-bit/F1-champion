# F1 Champion 🏁

한국어로 F1 시즌 일정과 드라이버·컨스트럭터 순위를 확인하는 반응형 팬 대시보드입니다.

## 실행하기
- `index.html`을 브라우저에서 열거나 Vercel에서 이 저장소를 배포하세요.
- 빌드 명령어와 출력 디렉터리는 필요하지 않은 정적 사이트입니다.

## 데이터
- 공개 Jolpica F1 API 사용: https://api.jolpi.ca/ergast/f1/
- API 응답이나 네트워크 상황에 따라 데이터가 표시되지 않을 수 있습니다.
- F1 관련 상표는 각 권리자에게 속하며, 이 프로젝트는 비공식 팬 프로젝트입니다.

## 파일
- `index.html` — 페이지 구조
- `style.css` — 반응형 디자인
- `script.js` — 일정 및 순위 데이터 로딩
